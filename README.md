## ------------ GDG (GOOGLE DEVELOPER GROUP) TEAM AND MANAGEMENT APP ------------ ##

## INTRODUCTION:
GDG App is an event–based application designed for managing Google Developer Groups activities for Campuses Societies. The app provides event schedules, speakers, workshops, community updates, and announcements
in one user-friendly platform.

## FEATURES:
1- User Authentication (Email/Google Sign-in)
2- Event schedule & registration
3- News & community updates
4- Push notifications for new events
5- Save/Bookmark events
6- User profile dashboard

## TECH AND AREA:
 Area --> Technology 
1- Frontend --> Flutter 
2- Backend  --> Firebase 
3- Database --> Firebase Firestore 
4- State Management --> Provider / Riverpod / Bloc 
5- Authentication --> Firebase Auth 


## BRANCH STRATEGY:
1- `main`      --> Production, stable release 
2- `dev`       --> Active development branch 
3- `feature/*` --> Work on new features (merged into `dev`) 

## Recommended Workflow
1. Create an Issue → assign it to yourself
2. Create feature branch → `feature/issue-name`
3. Develop feature → push commits
4. Submit Pull Request → `feature/*` → `dev`
5. After testing → merge `dev` → `main`

## FOLDER STRUCTURE:
lib/

## CONTRIBUTION RULES:
